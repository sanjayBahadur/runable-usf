# Runable Module Build Order

Build the app in this order.

## Core Local Demo

1. `00-types-constants.md`
2. `01-geometry-engine.md`
3. `02-territory-engine.md`
4. `03-demo-mode.md`
5. `04-map-rendering.md`

At this point the app should show:
- campus map
- campus boundary
- demo territory claims
- overlapping group ownership
- issue pins
- sighting pins

## Interactive Demo Features

6. `05-pixel-art.md`
7. `06-issues.md`
8. `07-leaderboards-feed.md`

At this point the app should support:
- painting owned cells
- reporting issues
- fixing issues
- points
- feed events
- leaderboards

## Real App Features

9. `08-supabase-auth.md`
10. `09-run-tracking.md`
11. `10-sightings-landmarks.md`
12. `11-periods-archives.md`

At this point the app starts becoming real:
- accounts
- groups
- database
- photo upload
- live GPS tracking
- sightings
- archives

## Optional Wow Feature

13. `12-ai-photo-verification.md`

Only build this if the main demo already works.
